This bounded pilot implements Nicolas's explicit requirement that some questions use the entire context. It applies only to the separately pinned cross-context profile in the new 4,096-assignment window starting 137729. Earlier jobs, data and experiments are unchanged.

A seeded 20% selection requires genuine dependency on every designated substantive evidence block. Include at least three non-overlapping essential blocks placed in the beginning, middle and end thirds of the context. The question must combine them. Do not provide a final summary that directly answers the question or makes an earlier block unnecessary. Not every word must be necessary; appropriate distractors can test relevance, but never add filler or padding to meet a length target. Keep the original operation, language, source, answerability, probability mechanism, IDK and complete choice-count contract.

Selected examples have seeded full-prompt token targets of 1,000–1,999, 2,000–3,999 or 4,000–8,000 tokens. Measure the exact canonical formatted prompt, including the question, full choices and special tokens, with the pinned local Qwen tokenizer and truncation disabled. The hard ceiling is 10,240 tokens, which is the proved training capacity; the architectural 40,960-token window has not been tested. Evidence must be substantive enough to justify its length. Long input alone does not establish context dependency.

Keep author_dependency_evidence outside learner input in the job's separate author-only JSONL evidence sidecar. Record exact context character offsets for the essential blocks, each block's dependency effect and a specific ablation rationale, a combined dependency rationale, and self-review claims that there is no summary shortcut or padding. For answerable tasks, removing or changing each block must change the answer or target distribution, or make it undetermined. For an unanswerable task, the combined evidence must establish which information remains missing or which alternatives remain unresolved; an ablation may change that analysis while leaving the final IDK label unchanged. Do not force an IDK-label change that conflicts with the original contract.

The adapter checks the structural claims, exact offsets, pins and complete prompt length. Author rationales are self-checks, not empirical ablation results or semantic proof. Never describe this as an ablation benchmark. A genuine incompatibility is a precise immutable skip, separately counted against the selected cohort denominator. All new jobs must use the cross-context adapter for durable append; ordinary unselected questions keep the unchanged draft schema. No bulk second-LLM semantic review is authorized.
