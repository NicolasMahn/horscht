# Probability-v2 decision metrics

`dataset_factory.decision_metrics` provides pure Python metrics for categorical probability-v2 targets and answerability decisions. Its score helpers accept soft distributions and hard-label one-hot distributions.

The categorical cross-entropy is `-Σ target[i] log(predicted[i])`, in nats. A zero target mass contributes zero; positive target mass with predicted probability zero gives positive infinity. The categorical Brier score is the sum `Σ (predicted[i] - target[i])²`; it is not divided by the number of choices. These proper scores describe the predicted distribution and stay separate from decision utility.

The task-grounded abstention or IDK option is an ordinary class in the choice vector. For unanswerable rows its target is one-hot on that class, so selecting it earns `+1`. For answerable rows its target mass is zero; selecting it is a false task answer and costs `λ`. Selecting a wrong class costs `λ` as well. A confidence rejection is an external action (`None`) and earns zero on either answerability status. It is never counted as a correct IDK answer.

For penalty `λ ≥ 0`, the substantive-choice threshold is `λ / (1 + λ)`. `threshold_action` finds the highest predicted probability among choices other than task IDK; it selects that choice when its probability is at least the threshold and otherwise externally rejects. A boundary value is accepted. The function uses probabilities as supplied and does not calibrate them. The threshold's decision-theoretic interpretation requires probabilities calibrated for the relevant outcomes.

`evaluate_decision_row` reports proper scores, expected utility for the task-class argmax, expected utility under the threshold policy, and the always-answer and all-reject actions. Its task-class argmax diagnostics include IDK: `unanswerable_idk_correct` and `false_idk` therefore measure raw class prediction before confidence rejection. `evaluate_decision_rows` aggregates those metrics. Its `answerable_coverage` is the share of answerable rows accepted by the threshold policy; `unanswerable_idk_recall` and `false_idk_rate` use the raw task-class argmax. When a report has no rows of a status, that status's rate is `null` (`None` in Python).

The aggregate `selective_risk` is the mean expected error mass among answerable rows accepted by the threshold policy. For each accepted row, expected error mass is `1 − target_distribution[selected_substantive_choice]`; this gives fractional risk for soft targets and ordinary zero-or-one error for hard labels. Rejected rows and unanswerable rows do not contribute. If no answerable rows are accepted, selective risk is `null`.

`risk_coverage_curve` sweeps the maximum predicted probability among substantive choices on answerable rows. It starts at zero coverage with undefined risk, then adds rows from highest to lowest confidence. Rows with exactly equal confidence are included together, so the curve has one point per distinct confidence value and is independent of input order within ties. Coverage is measured against all answerable rows; each point's risk is the mean expected error mass among the rows covered at that threshold. The curve is empty when the report has no answerable rows.

`source_kind_stratification` contains a report for each value of `distribution_source_kind`, with the same proper scores, decision metrics, baselines, and risk–coverage curve as the overall report. Rows without that field are grouped under `distribution_source_kind: null`; this keeps hard-label rows, which do not carry a soft-distribution source kind, visible without inventing one. Strata are listed in sorted order, with the null group last.

The always-answer baseline always selects the highest-probability substantive choice, regardless of its confidence. The all-reject baseline externally rejects every row and has zero utility. Both are scored with the same `+1` correct and `−λ` wrong-choice utility as the evaluated decisions.
