Decide answerability for the exact question asked. A context can omit a fact while still fully answering a question about which fact is missing. If the question asks which measurement or detail is needed, and a substantive choice correctly names it, IDK is not the correct answer. An immutable unanswerable assignment must instead ask for a value, event or conclusion that the supplied information cannot determine, with genuinely unresolved substantive alternatives and an explicit localized IDK choice.

For example, a known fair mechanism may determine the probability law while leaving an unseen realized result unknown. A question about the law is answerable. A question about the unseen result can be unanswerable. A question about which observation would reveal the result can again be answerable. Keep these tasks distinct; do not use arbitrary uncertainty to manufacture IDK, and do not add missing facts to an immutable unanswerable plan.

Before append, connect the question, choices and explanation to the same requested target. For an unanswerable row, check that no substantive choice already answers that target and that the missing information matters. If the assignment cannot be authored coherently, use a precise scoped skip. If the author discovers a defect after append, record an exact-ID exclusion and preserve the raw row.
